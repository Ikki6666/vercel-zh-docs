**Vercel 文档中文版**是 [vercel.com/docs](https://vercel.com/docs) 的社区中文翻译项目。

> [!IMPORTANT]
> 本站为**非官方**社区翻译，内容版权归 Vercel 所有。若页面与官方英文版不一致，以[官方文档](https://vercel.com/docs)为准。每页顶部的「查看英文原文」链接指向对应的官方页面。

## 如何使用本站

- 左侧导航结构与官方文档一致；已翻译页面为中文，未翻译页面暂以英文原文展示。
- 每页会标注翻译所基于的官方版本日期，落后较多时请优先参考英文原文。

## 项目状态

- 同步范围：vercel.com/docs 全站（约 1250 页），知识库（/kb）暂未纳入。
- 同步频率：上游每周自动同步，翻译按批次推进。
- 翻译状态统计见仓库 `make status`。

## 参与贡献

翻译校对、术语建议、问题反馈均欢迎到 GitHub 仓库提交 Issue 或 Pull Request。
术语表位于仓库 `glossary/terms.json`，欢迎补充。
